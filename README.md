# Reinforcement Learning Projects 🤖

A collection of my Reinforcement Learning projects implemented while learning and exploring different RL algorithms and environments.

This repository demonstrates the progression from **Tabular Reinforcement Learning** to **Deep Reinforcement Learning** through practical projects.

---

## 📂 Projects

### 1. Cliff Walking 🧗

A classic GridWorld Reinforcement Learning environment used to understand how an agent learns an optimal policy while avoiding the cliff.

**Algorithms:**
- Q-Learning
- SARSA

**Concepts Covered:**
- Q-Table
- State and Action Spaces
- Exploration vs Exploitation
- Epsilon-Greedy Policy
- Temporal Difference Learning
- Reward Optimization
- Q-Learning vs SARSA

📁 [`CliffWalking/`](./CliffWalking)

---

### 2. Flappy Bird RL 🐦

A Reinforcement Learning implementation where an agent learns to play Flappy Bird by interacting with the game environment.

**Algorithm:**
- Deep Q-Network (DQN)

**Concepts Covered:**
- Deep Reinforcement Learning
- Neural Networks
- Experience Replay
- Q-Values
- Epsilon-Greedy Exploration
- Target Network
- Training and Evaluation
- Game Environment Interaction

📁 [`FLAPPYBIRD_RL/`](./FLAPPYBIRD_RL)
